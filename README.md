# 🤖 Miner Monitor Bot (V.1.0)

บอทเฝ้าเหมืองขุด Crypto และเช็คสถานะ Network ภายในโรงงาน
พัฒนาโดย: [ชื่อของคุณ]

## 🚀 ฟีเจอร์หลัก
- เช็คสถานะ IP Address จำนวนมากได้พร้อมกัน
- แสดงผลสถานะ ONLINE / DEAD
- ทำงานอัตโนมัติทุก 1 นาทีผ่าน Cronjob

## 🛠️ วิธีติดตั้ง
1. Clone โปรเจกต์
2. ตั้งค่า IP ที่ต้องการในไฟล์ `miner_bot.py`
3. รันคำสั่ง `python3 miner_bot.py`
